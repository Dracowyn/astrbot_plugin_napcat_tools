# astrbot_plugin_napcat_tools

让 AstrBot 的 LLM 在 QQ 里像真人一样行动：戳一戳、贴表情回应、查资料、撤回、选择不回复；需要时也能做禁言、设精华等群管操作。

## 设计原则

- **只注册 LLM 工具**。不挂任何事件钩子，不注入提示词，不改写回复格式（不会强制引用消息），也不抢其他插件的事件。唯一的入口就是 LLM 调用工具。
- **关掉的工具不注册**。LLM 看不到它的 schema，也不占上下文。在 WebUI 保存配置后，插件会自动重载。
- **只用 AstrBot 公开 API**（`astrbot.api.*`），降低 AstrBot 升级导致插件失效的风险。
- **目标从当前消息里解析**。LLM 看不到消息 ID，所以操作对象取自"用户引用的那条消息 / 用户这条消息 / 被 @ 的人 / 发言人本人"。

## 支持的平台

只支持 aiocqhttp（OneBot v11），以 [NapCat](https://github.com/NapNeko/NapCatQQ) 为主要目标。戳一戳、表情回应等属于 NapCat 扩展接口，在其他 OneBot 实现上可能不可用；不可用时工具会返回明确的错误，由 LLM 转告用户。

## 工具

| 工具 | 默认 | 说明 |
|---|---|---|
| `qq_poke` | 开 | 戳一戳，群聊和私聊都可用 |
| `qq_react_emoji` | 开 | 给引用的消息或当前消息贴表情，内置 20 个常用表情 |
| `qq_get_user_info` | 开 | 群成员信息（名片、角色、头衔、等级、入群时间）和资料卡；对方隐藏或没填的字段自然缺失 |
| `qq_recall_own_message` | 开 | 撤回用户引用的、Bot 自己发的消息 |
| `qq_stay_silent` | 开 | 本轮不回复；被 @、被引用、私聊或唤醒词触发时会被拒绝 |
| `qq_set_my_card` | 关 | 修改 Bot 自己的群名片（任何成员都能触发，开启前请考虑冒充风险） |
| `qq_view_avatar` | 关 | 看头像：配置了看图模型时由它描述成文字，否则把图片交给当前模型（需要多模态） |
| `qq_mute_member` | 关 | 禁言或解禁（时长 0），受单次时长上限约束 |
| `qq_recall_message` | 关 | 撤回用户引用的任意消息 |
| `qq_set_essence` | 关 | 设为精华消息 |
| `qq_set_member_card` | 关 | 修改他人群名片 |

指定用户的参数支持以下写法：`sender`（发言人）、`quoted_sender`（被引用消息的作者）、`at` / `at:N`（第 N 个被 @ 的人）、QQ 号、昵称或群名片关键词。

**管理工具只接受 `quoted_sender` 和 `at`**：目标必须由请求者在自己这条消息里 @ 或引用出来。这样既不会误伤同名的人，也能防止有人在聊天记录里写"下次禁言 12345"来诱导 LLM。

## 权限

管理工具（禁言、撤回他人消息、设精华、改他人名片）需要同时满足：

1. 用户**直接对 Bot 说话**：@ Bot、引用 Bot 或使用唤醒词。群聊主动回复的轮次里不会执行管理操作。
2. **触发本轮对话的发言人**是 AstrBot 管理员，或本群群主/管理员（后者可在配置里关闭）。
3. Bot 自己是群管理员。另外，不能对群主操作；对管理员操作时，要求 Bot 是群主，且请求者是群主或 AstrBot 管理员，避免管理员借 Bot 越权处理其他管理员。

如果还想多一层保险，可以在 WebUI「扩展 → 组件」里把单个工具设为仅 AstrBot 管理员可用。

## 已知限制

- AstrBot 的"会话管理"里按群禁用插件，目前只作用于事件处理器，**对 LLM 工具不生效**。需要在某个群停用这些工具时，请暂时通过关闭对应工具的开关来实现。
- AstrBot 不记录 Bot 发出消息的 ID，所以只能撤回用户**引用**的消息，无法处理"撤回你刚才那句"。
- 表情 ID 来自 QQ 表情表，尚未在所有 NapCat 版本上逐一验证。
- `qq_stay_silent` 只能阻止它之后的回复。如果 LLM 在调用它的同一条响应里已经输出了文字，这段文字仍会发出。
